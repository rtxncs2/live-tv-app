This is a live tv app for Linux. Working fine in Debian 13. 

Just download the appimage from https://github.com/rtxncs2/live-tv-app/blob/main/IPTVPlayer-x86_64.AppImage and run these commands below to run the app 

cd Downloads
sudo apt install python3-vlc vlc
chmod +x IPTVPlayer-x86_64.AppImage
./IPTVPlayer-x86_64.AppImage
